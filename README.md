# 拾音工作台 · Shiyin Studio

原生 macOS 文件检索与歌曲查重工具。当前版本 **0.1.3**。

## 功能

- 文件名实时搜索、多关键词匹配、类型与目录过滤、列排序。
- 表头右键选择显示 BPM、KEY、时长、码率、格式等列，保存显示设置。
- 媒体信息读取、Quick Look 预览、菜单栏搜索、文件拖放、复制、移动和重命名。
- 选中歌曲或检索目录直接送入查重，先核对范围再手动开始。
- 整首频谱分析、快速时序指纹索引与原有完整筛选模式。
- CPU 并发设置、Metal GPU 比对、CPU/GPU 协同、GPU 批次与芯片建议。
- 暂停/继续/停止、进度计数、缓存、批量勾选、两首或三首同步试听。
- 跟随系统浅色/深色模式；确认后移到废纸篓，不清空废纸篓。

## 环境

- Apple Silicon Mac，macOS 14 或更新版本。
- 构建需 Xcode 或 Xcode Command Line Tools 与 macOS SDK。
- 无 Swift Package 网络依赖。可选 ffprobe 仅扩展媒体属性读取，不自动安装。

## 本地构建

在仓库根目录运行：

```sh
zsh build.command
```

应用输出到 `dist/拾音工作台.app`，采用本机临时签名。当前未提供 Developer ID 签名或 Apple 公证。

文件搜索回归测试：

```sh
zsh 搜索回归测试.command
```

测试需要系统 Python 3 生成测试媒体；测试在临时目录操作样本，不应把个人音乐加入测试数据。

## 目录

| 路径 | 内容 |

| `Search/` | 文件搜索、媒体信息、SQLite 索引和文件操作 |

| `Resources/` | 简体中文本地化资源 |

## 注意

BPM / KEY 读取现有媒体标签，不进行自动节拍或调性检测。相似分数不是准确率或文件内容完全一致的证明。快速指纹索引可能漏检，建议对已知重复歌曲使用完整筛选模式对照。变速、移调、现场与不同混音版本可能无法匹配。GPU 建议为保守起始值，不保证最优速度。

选择显示列、扫描和缓存不会修改音乐内容；移动、重命名和移到废纸篓由用户明确触发。首次扫描仍可能较慢，大曲库需自行验证性能。

详细操作见 [使用说明](docs/USAGE.zh-CN.md)。版本记录见 [更新记录](docs/CHANGELOG.zh-CN.md)。

## 数据存储

全部媒体分析在本机完成。文件索引存储于 `~/Library/Application Support/ShiyinStudio/`，音频与比对缓存存储于 `~/Library/Caches/local.shiyin.studio/`。用户文件、缓存和本机路径记录不随本仓库上传。
