# 拾音工作台 0.1.3

适用于 Apple 芯片 Mac，macOS 14 或更高版本。此版将拾音搜索 1.1.2 与听纹歌曲查重 1.9.1 放进同一个应用、同一个主窗口。原来的两个应用保留，可独立运行。全部处理在本机进行。

## 0.1.3 搜索列表显示列

在文件搜索列表顶部的列标题（例如“文件名”“BPM”“KEY”）上点击鼠标右键，菜单中勾选代表显示，取消勾选代表隐藏。支持 BPM、KEY、时长、分辨率、FPS、码率、格式、文件大小、文件位置；文件名列固定保留。选择“显示全部列”可恢复全部显示。

设置自动保存，重新启动仍保留，并在主窗口和菜单栏搜索框同步。隐藏只影响界面显示，不删除媒体标签，不改变文件或索引。点击仍显示的列标题照常排序；隐藏当前排序列后恢复按文件名升序排列，避免仍按看不到的列排序。

## 0.1.2 添加目录中文化

检索目录选择器、查重范围选择器和批量勾选文件夹选择器使用中文标题、说明与确认按钮。应用声明简体中文资源，并在本应用内使用简体中文，使系统文件选择窗口的取消、搜索及侧栏等系统控件使用中文；不更改 macOS 全局语言，也不会翻译磁盘上自定义的文件名或文件夹名。

更新后请完全退出旧版，再打开此版，使系统文件选择窗口使用新的语言设置。目录、索引、缓存和浅深色自动外观继续沿用。

## 0.1.1 界面更新

查重页取消固定深色背景与强制外观，随 macOS 当前的浅色或深色模式自动显示；系统设为“自动”时也随系统生效，无需在软件里另设主题。切换时不需要重启软件。

查重设置使用紧凑标题，主标题、分区、结果卡片和分隔线更接近拾音搜索的原生样式。批量勾选、同步试听和已勾选列表也使用自适应颜色。算法、扫描范围和缓存格式沿用 0.1.0，原目录设置可直接使用。

## 开始使用

1. 解压并打开「拾音工作台.app」。顶部在「文件搜索」「歌曲查重」之间切换。
2. 在文件搜索页点击「检索目录…」添加文件夹；或者点击「导入原拾音目录…」，确认后只导入原拾音保存的目录设置。本版使用独立索引，首次需要重新建立。
3. 输入文件名关键词，选择需要检查的至少两首歌曲，点击「所选歌曲查重」。也可右键选择同名操作。只送入所选的受支持音频文件，不扩大到所在文件夹，视频和其他文件会跳过。
4. 要检查整个曲库，点击顶部「检索目录查重」，将所有已添加的检索目录送入查重页。也可以在查重页点击加号，直接添加歌曲或文件夹。
5. 核对查重范围、CPU/GPU 和候选检索设置，点击「开始频谱扫描」。送入范围不会自动开始扫描。
6. 完成后可批量勾选、两首或三首同步试听、导出 CSV；「查看已勾选」可核对完整路径。「移到废纸篓」仍需再次确认，不清空废纸篓。

左侧设置较长，可向下滚动找到开始、暂停和停止按钮。窗口可调整大小。

## 保留的功能

- 文件搜索：关键词、目录和类型过滤、表格排序、媒体属性、菜单栏搜索、Quick Look、拖出文件、复制、移动和重命名。
- 歌曲查重：整首频谱指纹、快速索引/原有完整筛选、CPU 并发数、CPU/GPU 协同、GPU 自动建议及 64–1024 对手动批次、缓存、暂停/停止、进度与计数。
- 搜索页、查重页及批量勾选、试听、已选文件弹窗均跟随系统浅色/深色外观，使用系统背景、文字和强调色。
- BPM / KEY 仍读取已有标签，不进行自动节拍或调性检测。安装可选 ffprobe 仅扩展媒体信息读取，不会让查重自动支持所有音频格式。

## 第一版的衔接规则

- 搜索目录通过「检索目录查重」明确送入，查重页可以单独调整范围；改变搜索目录不会偷偷替换正在使用的查重范围。
- 切换页面保留搜索与查重状态，试听暂停。查重运行时仍可进行文件名搜索，但本软件的拖出、移动、粘贴和重命名暂不可用，避免范围与结果失效；先停止查重再整理文件。
- 通过本软件重命名或移动前，会清除旧查重结果、勾选和试听，之后需要重新扫描。拖出文件结束后也保守清除结果并刷新搜索索引，即使拖动最终取消。
- 查重移到废纸篓后通知搜索索引重新核对。外部软件改动文件仍可能让正在显示的查重结果过期；移到废纸篓前保留文件大小、修改时间和直接匹配副本存在检查。
- 关闭主窗口后保留菜单栏入口；扫描中请先停止再退出。

## 缓存与兼容

试用版使用独立应用标识 `local.shiyin.studio`，文件索引在 `~/Library/Application Support/ShiyinStudio/index.sqlite`，音频和比对缓存位于 `~/Library/Caches/local.shiyin.studio/`，废纸篓操作记录在 `~/Library/Application Support/拾音工作台/`。

不会改写原拾音索引或原听纹缓存。原来的性能设置和音频指纹不会自动迁移，首次整合版扫描可能较慢。搜索数据库和音频指纹用途不同，分别保存；日常搜索不会启动整首音频查重。

## 已知限制

本版在首个整合版本上统一查重页的系统配色与原生分区样式。快速索引可能漏检；建议先在包含已知重复歌曲的小目录中对照「原有完整筛选」。同样 BPM、调性或音乐风格不代表同一录音，评分不是准确率或逐字节一致证明。变速、移调、现场及不同混音可能无法匹配。

GPU 推荐是按芯片和内存给出的保守起点，不是最优测速值。手动批次为上限，实际会受指纹大小与待处理数量影响。

当前发布包仅含 Apple Silicon 版本。应用采用本地签名，未进行 Developer ID 公证，不应关闭系统安全机制。源码及本地构建脚本附在「源码」目录内；双击 build.command 可重新构建。
